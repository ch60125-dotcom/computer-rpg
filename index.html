📖 資訊勇者作戰手冊（重點秘笈）

遇到打不過的怪物嗎？先來這裡複習電腦快捷鍵與資安常識吧！

⌨️ 必背鍵盤快捷鍵魔法

• Ctrl + C：複製 (Copy)

• Ctrl + V：貼上 (形狀像膠水漏斗)

• Ctrl + X：剪下 (形狀像一把剪刀)

• Ctrl + Z：復原上一步 (不小心刪掉時的救星)

• Ctrl + A：全選所有內容 (All)

• Ctrl + S：儲存檔案 (Save)

🖥️ 電腦硬體五大支柱

• CPU (中央處理器)：電腦的大腦，負責計算與處理指令。

• RAM (記憶體)：電腦的書桌，暫存正在執行的程式，關機資料會消失。

• SSD / 硬碟：電腦的書櫃，永久保存作業與照片。

• 輸入設備：滑鼠、鍵盤、麥克風、掃描器（把資料送進電腦）。

• 輸出設備：螢幕、喇叭、印表機（把結果表現出來）。

📁 檔案格式與副檔名

• 圖片檔：.jpg、.png、.gif

• 聲音檔：.mp3、.wav

• 影片檔：.mp4、.avi

• 壓縮檔 / 執行檔：.zip (壓縮檔)、.exe (程式執行檔，來路不明切勿亂點！)

🛡️ 網路安全與資安防護

• 強密碼原則：混合英文大小寫、數字與符號，不可用生日或 123456。

• 網路釣魚 (Phishing)：假冒中獎或官方通知騙取帳密，切勿點擊不明連結。

• 公用電腦習慣：使用完畢務必「登出帳號」，不勾選記住密碼。
