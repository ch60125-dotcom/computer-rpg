📖 《資訊天書》電腦操作與資安秘笈

⌨️ 鍵盤快捷鍵心法

• Ctrl + C / V / X：複製 / 貼上 / 剪下

• Ctrl + Z / S / A：復原 / 儲存 / 全選

• Ctrl + F：在網頁或文件中「尋找關鍵字」

• F5：重新整理網頁｜Alt + F4：關閉視窗

• Home / End：游標移至該行最前面 / 最後面

🖥️ 硬體與網路設備

• CPU：中央處理器（大腦）｜GPU：顯示卡

• RAM：記憶體（暫存書桌，斷電資料消失）

• SSD / HDD：固態硬碟 / 傳統硬碟（永久書櫃）

• 容量單位：KB < MB < GB < TB (1TB 約 1024GB)

• Wi-Fi 分享器：發送無線網路訊號的設備

🧩 Scratch 運算思維與 AI

• 綠旗積木：當綠旗被點擊時（程式開始）

• 重複無限次：迴圈（Loop），讓動作持續執行

• 如果...那麼...：條件判斷（Selection）

• 舞台座標：中心點為 (X:0, Y:0)，X為左右、Y為上下

• AI 查證原則：生成式 AI 偶爾會產生錯誤資訊（幻覺），重要事實需多方查證

🛡️ 資安護體與 3-2-1 備份

• 雙重驗證 (2FA)：除了密碼外再加上手機驗證碼

• 3-2-1 備份原則：3份資料、2種不同媒介、1份異地/雲端保存，防範勒索病毒

• 公用電腦：使用無痕視窗或下課務必登出帳號
