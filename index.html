⌨️ 鍵盤快捷鍵心法

• Ctrl + C：複製 (Copy)

• Ctrl + V：貼上 (形狀像漏斗)

• Ctrl + X：剪下 (形狀像剪刀)

• Ctrl + Z：復原上一步 (救命後悔藥)

• Ctrl + A：全選 (All)

• Ctrl + S：儲存檔案 (Save)

🖥️ 硬體五大構造

• CPU (中央處理器)：電腦的大腦，負責運算。

• RAM (記憶體)：工作書桌，關機資料會消失。

• SSD / 硬碟：大書櫃，永久保存作業與照片。

• 輸入設備：滑鼠、鍵盤、麥克風、掃描器。

• 輸出設備：螢幕、喇叭、印表機。
